**How Clients Fit in Launchpad**

Each Client is a customer of the Channel Partner, an organisation or tenant with its own workspace. Inside each Client, you manage:

- **Buildings:** Physical sites they monitor, like offices, campuses, and facilities.
- **Users:** People who access those buildings.
- **Roles and Permissions:** Define what each user is authorised to do.
- **Authentication & Security (SSO):** How users sign in securely.
- **Service Accounts:** Automate integrations or API connections.
- **Trusted Organisations:** Share data or access with other clients.

Create or open a client when:

- A Channel Partner is onboarding a new customer.
- You need to group buildings and users for one customer.
- You must apply different access or security settings for one organization.

### Client Setup

Create and configure the essential components of a client workspace.\
These tasks help you get a new client operational in Launchpad.

1. [<u>Add Your First Building</u>](https://help.kodelabs.com/portal/en/kb/articles/tutorial-your-portfolio-add-your-first-building-in-launchpad-22-9-2025-1): Create the client’s first building, define its details, and configure its environment.
2. [<u>Assign Users to Buildings</u>](https://help.kodelabs.com/portal/en/kb/articles/tutorial-manage-access-assign-a-user-to-a-building-in-cloud-bms-22-9-2025-1): Add users to the client and assign them access to specific buildings.
3. Manage[<u>Buildings</u>](https://help.kodelabs.com/portal/en/kb/articles/buildings-22-9-2025-1)  and[<u>Users</u>](https://help.kodelabs.com/portal/en/kb/articles/users-clients-22-9-2025-1) : Edit building details, update user accounts, and adjust building assignments as needed.

### Client Security and Access

Once the client’s basic setup is complete, configure access and authentication to ensure secure operations.\
This section covers how users are authorized, authenticated, and integrated across KODE OS and Launchpad.

1. [<u>Roles and Permissions:</u>](https://help.kodelabs.com/portal/en/kb/articles/manage-roles-and-permissions-22-9-2025-1) Define roles to control what users can view, create, or modify. Manage permissions for building-level and portfolio-level access.
2. [<u>Authentication & SSO</u>](https://help.kodelabs.com/portal/en/kb/articles/single-sign-on-sso-22-9-2025-1): Configure Single Sign-On (SSO) to connect your identity provider.
3. [<u>MFA, Password, and Timeout Policies:</u>](https://help.kodelabs.com/portal/en/kb/articles/authentication-security-22-9-2025-1) Enforce Multi-Factor Authentication, password complexity, and session timeout rules to strengthen login security.
4. [<u>Service Accounts</u>](https://help.kodelabs.com/portal/en/kb/articles/service-account-setup-22-9-2025): Create secure credentials for integrations or automated API connections.
5. [<u>Trusted Organizations</u>](https://help.kodelabs.com/portal/en/kb/articles/trusted-organizations-22-9-2025-1): Manage trust relationships and security policies between your organization and external partners.

Client in Launchpad is a dedicated environment that contains its own users, buildings, and security framework.\
By structuring clients this way, Channel Partners can manage multiple organizations independently while maintaining data isolation, security, and scalability across all workspaces.
