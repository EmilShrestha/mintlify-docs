<Info>
  - Site-level permissions only apply when a user is assigned to that building.
  - Portfolio-level permissions apply globally.
</Info>

For each module, you’ll find a description of what the permission enables and whether it grants view-only or edit access.

<Note>
  We update permissions as new modules are added to KODE OS.
</Note>

Permissions are grouped by:

- **Modules**: Functional areas such as BuildingBI or Launchpad.
- **Submodules**: Specific components under each module, such as Dashboards or Datasources.
- **Access Levels**: Define what actions can be performed within each submodule.

**Permissions Reference Table**

The permission structure is grouped by module. Each section lists its **submodules**, their **permissions**, **access levels**, and **descriptions**.
